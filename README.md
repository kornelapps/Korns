# Kornels Imagenes
Generador de imagenes para Android.
- Online: Pollinations (gratis, sin clave).
- Offline: Stable Diffusion 1.5 cuantizado (GGUF, Hugging Face second-state) con stable-diffusion.cpp
  (commit d637cfb) compilado para arm64 por GitHub Actions y empaquetado como libsdcli.so.
Sube a GitHub -> Actions -> descarga el artefacto `kornels-imagenes-apk`.
